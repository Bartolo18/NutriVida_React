# NutriVida en React

Proyecto DSY1104 de Bárbara Tolorza y Christopher Villa.

## Punto de partida

Este repositorio registra la integración y revisión por etapas de NutriVida V2. Se utiliza una base preparada con asistencia de ChatGPT y los ejemplos y aclaraciones del profesor. Los commits registran el trabajo que cada integrante realiza y comprueba desde su propia cuenta durante esta integración.

## Estado inicial

Vite inicia React. Las páginas y los formularios se migrarán en etapas posteriores; todavía no existen pruebas de los componentes del proyecto.

## Ejecutar

Con Node.js instalado: `npm ci` y `npm run dev`. Para comprobar la compilación: `npm run build`.
